# Changelog

## 0.3.0 — unreleased

- Отдельная публикация документации в GitHub Pages: base path из настроек Pages, проверенный артефакт и браузерная приёмка публичного URL после deploy.

- Локальный статический сайт документации: VitePress, русская навигация/поиск, справочник API и playground с inspect/двумя получателями; проверки ссылок и браузера в корне и подпути, отдельный CI. Публичная публикация ещё не выполнена.

- Самостоятельный Angular 21 AOT-пример из установленного tarball: директива жизненного цикла, динамические поля/кнопки, Router и очистка слушателей; браузерные сценарии добавлены в check:all.

- Браузерная IIFE с глобальным TrackEvents; самостоятельные HTML/JS-примеры classic script и ESM, проверки готовых assets без Vite, измерение размеров и сбора контекста.

- Отдельные нейтральные получатели GA4, GTM и Umami: передаваемые SDK-клиенты, адресная отправка, mapping, проверки payload и изолированные ошибки; тесты SDK-контрактов без реальной отправки.

- Конфигурация и исполняемые JavaScript-примеры нескольких получателей/областей; блокирующая ambiguous-field для коллизий атрибутов одного элемента.
- Нейтральный `createTracker`: data-track разметка, schema/events, типизация и валидация.
- Inspect с происхождением полей, перекрытиями, границами, issues и выбором получателей.
- Start/stop/destroy, автоматические click/change/submit и ручные track/trackElement.
- Настройка capture для сбора контекста до удаления элементов обработчиками интерфейса; фаза всплытия остаётся значением по умолчанию.
- Получатели dataLayer/callback: фильтры, transform, изоляция данных, onError и flush.
- Исправления legacy: границы, пустые root-атрибуты, нормализация, повторная инициализация, input-события, немедленная отправка кнопок.
- Исправленная упаковка ESM/CommonJS и NodeNext-типов; проверка установленного tarball.
- Демо HTML и React StrictMode, проверки DOM и реального браузера, CI и документация миграции.

Имя пакета и default legacy-export сохранены. Различия поведения описаны в docs/MIGRATION.md. Эта версия ещё не опубликована.
