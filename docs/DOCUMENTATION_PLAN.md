## Формат и выбор генератора

Сохраняем Markdown и относительные ссылки как переносимый источник. Предлагается статическая сборка с локальным preview и отдельным workflow GitHub Pages. Конкретный генератор пока не выбран: сравнить небольшой набор по поиску, навигации, Markdown, сборке из подпути и стоимости поддержки; решение записать перед установкой зависимостей. В этой задаче движок и workflow публикации не добавляются.

Обязательные свойства будущей сборки:

- Работать в `/google-events/`, в корне домена и после переименования репозитория через один base path.
- Строиться без доступов к аналитическим аккаунтам, без загрузки SDK и без отправки посещений документации в рабочие проекты.
- Поддерживать прямой URL раздела и assets внутри подпути; внутренние ссылки не привязывать к текущему owner.
- Разделять preview PR, проверку библиотеки и публикацию сайта. Каталог документации не должен заменять dist библиотеки или существующие демо.
- Показывать версию API и состояние интеграций. Старые рецепты SDK нельзя автоматически считать совместимыми с новой версией.
- Проверять локальные ссылки и примеры; для внешних источников хранить дату исследования. Недоступность внешнего сайта при CI не должна делать библиотеку неустанавливаемой.

Сейчас docs целиком включается в npm tarball; добавленные страницы внесены в проверку состава пакета. Пересмотр состава поставки — отдельное решение, если каталог исследований станет слишком большим.

## Шаблон страницы интеграции

Каждая карточка содержит дату, статус реализации, подключение SDK, event-вызов, mapping, routing аккаунтов, readiness/ошибки, автоматический сбор/дубли, отключение/локальное тестирование, ограничения и ссылки. Факты из источников отделяются от наших предложений адаптера. Непроверенные ограничения явно помечаются; количественные лимиты не переносятся между SDK.

## Приёмка публикации на этапе 7

Читатель должен по сайту получить пакет, разметить вложенные области, отправить одно действие двум сервисам и объяснить результат через inspect. Проверить поиск, прямые ссылки, подпуть, адаптивное чтение и отсутствие неработающих примеров. На текущем этапе готова структура и содержимое начальных страниц; сама публикация остаётся этапом 7.
