# Размер и стоимость сбора контекста

Воспроизведение в репозитории библиотеки: `npm ci`, установка браузера Playwright (`npx playwright install chromium` на Linux; установленный Edge на Windows), затем `npm run measure`. Для обновления сохранённого снимка: `npm run measure -- --write`.

Скрипт заново собирает пакет, считает байты и gzip level 9 без source maps и открывает готовую IIFE в headless-браузере. Вызов `trackElement()` включает поиск действия/границы, сбор полей, schema и подготовку отправки с `receivers: []`. SDK, сеть, обработчик клика, listeners и rendering в измерение не входят. Это стоимость полного вызова сбора, а не изолированный таймер одной функции обхода.

Два дерева: 12 и 256 предков кнопки; price=0 на root, placement повторяется каждые четыре уровня. Для каждого: 200 прогревочных вызовов, 25 серий по 200 вызовов. Медиана и p95 относятся к средним временам серий, а не к распределению отдельных кликов. Бюджет времени в CI не задаётся: нагрузка машины и браузер влияют на результат.

[Сохранённый JSON](benchmarks/browser.json) содержит реальные размеры, SHA-256 сборок, все серии, версию браузера/Node, ОС, CPU и время запуска. Сборки не минифицированы; gzip — оценка сжатия файла, не размер всех запросов страницы. Сравнивайте повторные замеры в одинаковых условиях. Показатели одного локального компьютера не являются гарантией для устройств пользователей.
