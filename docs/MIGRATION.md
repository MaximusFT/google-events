# Переход к нейтральному API

0.3.0 добавляет `createTracker`, не заменяя default export `googleEvents` или `createGoogleEvents`. Старый и новый режимы имеют разные форматы событий и разные атрибуты; смешивать их в одном экземпляре не требуется.

| Legacy | Нейтральный вариант |
| --- | --- |
| `createGoogleEvents().init()` | `createTracker(config).start()` |
| `data-gtm-event` обозначает область | `data-track-root` обозначает область |
| `data-event="favorite_add"` на действии | `data-track-event="favorite_add"` |
| `data-gtm-link-place` | `data-track-placement` |
| `data-ecomm-product-id` | `data-track-product-id` |
| `data-gtm-off` | `data-track-off` |
| `tags`/`map` | Явные атрибуты и schema с attribute |
| `event`, `action`, `data`, `ecommerce` | `name`, `trigger`, `properties` |
| Автосбор ссылок/кнопок внутри GTM-области | Только явно размеченные действия |
| Search по CSS-классу, drawer-переключатель | Явный trigger/имя и состояние от приложения |

Нейтральный режим не собирает значения форм, тексты, URL или ecommerce-поля автоматически. Параметры определяет ваша разметка; вывод в конкретную схему — transform адаптера. В частности, для GTM обычно нужен `{ event: event.name, ...event.properties }`, а для ecommerce GA4 нужны соответствующие items/currency/value, настроенные вами.

Новые строки не приводятся к нижнему регистру. Если отчётам нужно старое преобразование, задайте его явно в transform соответствующего получателя. Неверное ближайшее значение не заменяется родительским; inspect показывает его и перекрытые источники.

Рекомендуемый переход: оставить работающий legacy-трекер, добавить новую разметку в отдельную область, создать нейтральный экземпляр с ограниченным root и callback-получателем для проверки. После сравнения payload отключить legacy-сбор в переведённой области и подключить нужные SDK/теги. Не запускать обе системы на одних бизнес-действиях без намерения получить дубли.

Исправления legacy относительно исходного 0.2.0 тоже меняют результаты: ограниченные области, сохранение регистра, повторные input-события и отсутствие таймера 500 мс. Подробности в [LEGACY.md](LEGACY.md). Публичный выпуск этой версии пока не выполнен.
