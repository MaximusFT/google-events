# Документация библиотеки событий

Разметьте контекст на контейнере, действие — на кнопке. Один сборщик наследует данные до ближайшего root и передаёт событие выбранным получателям. UI-фреймворк и аналитический сервис не определяют формат ядра.

Версия API: кандидат 0.3.0, пакет ещё не опубликован. [Сайт документации](https://maximusft.github.io/google-events/) с локальным поиском и playground опубликован и проверен по публичному адресу. Наличие карточки сервиса не означает наличие его встроенного адаптера.
