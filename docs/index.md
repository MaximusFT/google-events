# Документация библиотеки событий

Разметьте контекст на контейнере, действие — на кнопке. Один сборщик наследует данные до ближайшего root и передаёт событие выбранным получателям. UI-фреймворк и аналитический сервис не определяют формат ядра.

Версия: локальный кандидат 0.3.0. Это исходники будущего сайта документации; статический сайт пока не собран и не опубликован. Наличие карточки сервиса не означает наличие его встроенного адаптера.
