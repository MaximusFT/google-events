# Пилот на ma-x.im

Дата: 4 октября 2026 года. Интеграция выполнена локально в отдельном проекте `ma-x.im-v3` с Next.js 15, React 19 и статическим экспортом. Публикация сайта и пакета не выполнялась.

## Подключение

Сайт устанавливает собранный пакет из tarball в своей папке `vendor`, без зависимости от абсолютного пути к исходникам библиотеки. `AnalyticsTracker` — маленький клиентский компонент в общем layout: запускает один экземпляр после mount, снимает слушатели при unmount. Страницы и карточки остаются серверными компонентами; разметка попадает в статический HTML.

Используется `capture: true`: это позволяет прочитать контекст до того, как React удалит ссылку при закрытии меню. Пилот обнаружил потерю кликов на desktop-dropdown и мобильном меню в фазе всплытия. Для нового параметра добавлены проверки сохранения контекста, stopPropagation, повторного start и очистки слушателей.

Два получателя: `window.dataLayer` и существующий SDK Umami через адаптер сайта `umami.track(name, data)`. `page_path` добавляет интеграция в момент события; библиотека не извлекает URL автоматически. Для контактов сохраняется SDK-имя `contact-click`, прежние native-теги этих ссылок удалены для защиты от дублей. Остальные native-теги и автоматические pageviews сохранены.

SDK и адаптер ограничены доменами ma-x.im/www.ma-x.im: локальный просмотр пишет только в dataLayer. Отправка ждёт поздний SDK до трёх секунд; ошибка/таймаут не мешают второму получателю и UI, повторных отправок нет. Контракт проверен по [tracker functions](https://docs.umami.is/docs/tracker-functions) и [tracker configuration](https://docs.umami.is/docs/tracker-configuration).

## Словарь и контекст

| Событие | Контекст | Источник |
| --- | --- | --- |
| navigation_selected | section, placement, destination | Header: desktop/mobile |
| playbooks_toggled / menu_toggled | section, placement, state | Кнопки меню; state — запрошенное open/close |
| cv_download_requested | section, placement | Ссылка CV; событие не подтверждает скачивание |
| contact_selected | section, placement, method | Контактная секция и primary/secondary группы |
| article_selected | section, post_id, post_title, placement | Корень карточки и cover/title/read-more ссылки |
| tag_selected | section, post_id, post_title, placement, tag | Ссылка тега внутри карточки |

Карточка статьи хранит идентификатор и заголовок один раз, три ссылки наследуют их. Contact хранит section один раз, две группы задают placement; семь ссылок добавляют только имя действия и method. Дополнительных аналитических props для кнопок не потребовалось. Это описание структуры пилота, не замер экономии против предыдущей реализации.

Активация кнопок через Enter/Space вызывает обычный click и учитывается один раз. Произвольные нажатия клавиш и вводимый текст не собираются.

## Проверка

В сайте выполнить `npm exec -- next build` (сам статический экспорт; без запуска оптимизатора уже готовых изображений). Затем в репозитории библиотеки выполнить `npm run test:site`. Одиннадцать сценариев проверяют взаимодействия сайта и SDK-контракт: локальное исключение, два получателя, поздний SDK после навигации, SDK-rejection, отсутствие дублей контактов и script-error.

Тесты работают на готовой папке `out`, запрещая внешние сетевые запросы: тестовые посещения не отправляются в реальную аналитику. Для другого расположения экспорта установить `SITE_PILOT_DIR`. Обычный `check:all` остаётся независимым от второго проекта.

Результат: все одиннадцать сценариев прошли в Edge; Next.js экспортировал 316 страниц. Типы и ESLint изменённых компонентов прошли. Библиотека ранее прошла 46 Node/jsdom-сценариев, 13 браузерных сценариев демо и проверку чистой установки ESM/CommonJS/NodeNext пакета; при добавлении адаптера её runtime не менялся.

Для ручного inspect открыть локальный сайт с `?track-debug=1`, затем в DevTools вызвать `window.siteTracker.inspect(element)`. Сам inspect ничего не отправляет. События доступны в `window.dataLayer`; без debug-параметра экземпляр не экспортируется в window.

## Что ещё предстоит

После публикации сайта проверить поступление событий и параметров в реальной панели Umami. Локальные тесты с подставным SDK подтверждают вызовы адаптера, но не приём данных сервером. До публикации библиотеки отдельно решить окончательное имя/реестр и способ обновления локального tarball сайта.
