# Playground: от разметки к событию

Пример на сайте использует собранную библиотеку 0.3.0. Нажмите «Объяснить без отправки»: inspect покажет границу, источники полей, перекрытия и выбор получателей. Затем нажмите «В избранное» — одно действие попадёт в два локальных callback-получателя с разным маппингом.

Вложенный root содержит собственные product_id/price и не наследует available внешней карточки. Некорректная цена блокирует событие внешней карточки из-за required schema. «Отключить сбор» действует внутри внешней области; вложенный root изолирует и этот атрибут, поэтому для его отключения нужен off внутри собственной границы. [Правила off и root](CONTRACT.md) одинаковы для примера и пользовательского приложения.

Здесь нет реальных SDK и отправки в аналитические панели. Локальные callback показывают факт вызова получателя. Источники DOM преобразованы в id/tagName только для отображения; в отправляемые свойства они не входят. При уходе со страницы трекер снимает слушатели. В обычном Markdown предпросмотре интерактивная часть недоступна; существующие HTML-примеры остаются в examples/browser.
