# Подготовка первого пилота и выпуска

Локальная версия: 0.3.0. Это подготовленный кандидат; npm/GitHub-публикация не выполнена.

## Уже подготовлено

- Нейтральный контракт, схема типов, общий сборщик и inspect.
- Жизненный цикл, ручной/автоматический режимы и независимые получатели.
- Plain HTML, legacy и React StrictMode примеры.
- Локальный магазин с асинхронными исходами и интеграция в отдельный Next.js static-export сайт ma-x.im; отчёт в SITE_PILOT.md.
- Проверки алгоритма/DOM, реальные браузерные сценарии и установка пакета в чистый проект.
- ESM/CommonJS, объявления типов, MIT LICENSE, changelog и руководство миграции.

## Проверка перед выпуском

1. Выполнить `npm ci`, затем `npm run check:all` в выбранных средах. На Linux установить Chromium через Playwright.
2. Выполнить `npm pack` и проверить состав tarball. Проверка `test:package` автоматически ставит tarball в временный чистый проект и проверяет оба типа импортов.
3. Завершить пилот: локальная интеграция и вызовы адаптера Umami проверены на ma-x.im, но после публикации нужно подтвердить приём данных в панели. Пример магазина отдельно проверяет ошибки обязательных полей и подтверждённые бизнес-операции.
4. Проверить совместимость текущих потребителей по MIGRATION.md. Выбрать окончательное имя и реестр публикации. Сейчас сохранены историческое имя и GitHub Packages.
5. Обновить changelog из состояния unreleased, после авторизации публикации выпустить пакет и тег версии. Автоматическая публикация не настроена.

## Вопросы пилота

Сколько аналитических props удалось удалить из цепочки компонентов? Сколько повторов параметров исчезло с кнопок? Может ли разработчик подключиться по README и объяснить событие через inspect? Где понадобился ручной snapshot вместо DOM-обхода? Достигают ли события выбранных SDK/тегов, а не только callback/dataLayer?

Приём событий в реальной аналитической панели, фактические цифры производительности/размера и публичный выпуск не считаются завершёнными локальными тестами. Дополнительные интеграции, portals-реестр, междокументные мосты, AI-разметка и визуальный редактор — после базового пилота.
